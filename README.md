# Customer Purchase Analysis

## Project Overview
Analyzed customer purchase data to understand spending patterns, income levels, and purchase frequency. Built an interactive Power BI dashboard.

## Tools Used
- Power BI
- Excel

## What I Did
- Loaded customer data
- Created 4 KPI cards (Customers, Average Income, Average Age, Average Spending Score)
- Built Bar Chart, Donut Chart, and Column Chart
- Added Slicer for Membership Year

## Key Insights
- Customer spending patterns by age
- Income distribution
- Purchase frequency analysis

## Dashboard Features
- KPI Cards
- Bar Chart (Income by Age)
- Donut Chart (Customers by Age)
- Column Chart (Purchase Frequency)
- Slicer (Membership Year)
